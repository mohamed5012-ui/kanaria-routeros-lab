# kanaria-routeros-lab

تجارب على راوتر MikroTik حقيقي (صورة CHR جوه qemu) في GitHub Actions.

التجربة الحالية (`cards/`): سكربتات كروت الهوتسبوت اللي اللوحة بتولّدها، على RouterOS 6.47.9 و6.49.19 و7.24.5: إضافة 150 كارت، يوزر العميل بنفس الاسم مايتلمسش، تعطيل ومسح، تكرار الإضافة، وقراية الاستهلاك اللي بترجع للوحة.

مفيش هنا كود اللوحة ولا كلمات سر ولا عناوين حقيقية: السكربتات متولّدة ببيانات تجربة، والمستقبل سيرفر تجربة جوه الـ CI. كل تجربة بتقف لوحدها بعد 25 دقيقة بالكتير.
